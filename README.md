Arey! Yaad Aye?

## Overview
Arey! Yaad Aye? is a doctor-assisted cognitive engagement and memory assistance platform designed for elderly individuals experiencing memory decline and mild cognitive impairment.

The platform uses familiar family photographs, voice recordings, and personalized memory activities to encourage regular cognitive engagement in a comfortable and emotionally meaningful way.

## Target Users

### Primary Users
- Elderly Individuals
- Early-stage Dementia Patients
- Mild Cognitive Impairment Users

### Secondary Users
- Doctors
- Caregivers
- Family Members
